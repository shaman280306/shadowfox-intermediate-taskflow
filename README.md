# 🚀 TaskFlow — Task Management Dashboard

A modern and responsive task management dashboard built as the **ShadowFox Virtual Internship — Intermediate Project**.

TaskFlow allows users to create, manage, search, filter and track tasks through a clean productivity-focused interface.

---

## 🎯 Objective

The objective of this project is to build an interactive web application using core frontend technologies while demonstrating practical JavaScript concepts such as:

- DOM Manipulation
- Event Handling
- CRUD Operations
- Array Methods
- LocalStorage
- Dynamic UI Rendering
- Search and Filtering
- Theme Persistence
- Responsive Web Design

---

## ✨ Features

- ✅ Create tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ☑️ Mark tasks as completed
- 🔎 Search tasks
- 🎯 Filter by priority
- 📋 Filter by task status
- 📊 Real-time task statistics
- 📈 Completion progress percentage
- 🌙 Dark mode
- 💾 LocalStorage persistence
- 📱 Responsive design
- ⌨️ Escape key modal support
- 🛡️ Basic HTML escaping for user-entered content
